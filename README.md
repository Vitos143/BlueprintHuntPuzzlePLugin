# BlueprintHuntPuzzle - images

Artwork for the **BlueprintHuntPuzzle** Rust plugin (OUTSIDE hardcore server).
Players find 9 blueprint parts and see them come together in the `/parts` window.

## Layout
Each folder holds one blueprint, `part1.png` ... `part9.png`, 3x3, left to right, top to bottom (512x512 each):
- `recycler/` - Personal Recycler
- `m92/` - M92 Pistol
- `spas/` - Spas-12 Shotgun
- `sks/` - SKS
- `bolt/` - Bolt Action Rifle
- `rl/` - Rocket Launcher

Direct links used by the plugin:
`https://raw.githubusercontent.com/Vitos143/BlueprintHuntPuzzlePLugin/main/<folder>/partN.png`
